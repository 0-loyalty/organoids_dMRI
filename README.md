# Cortical Organoid Diffusion MRI

This repository accompanies the manuscript:

**Cortical organoid diffusion MRI reveals protocol-associated spatial reproducibility and increasing apparent diffusivity with diffusion time**

Andrés le Boeuf Fló et al.

Preprint: https://doi.org/10.64898/2026.09.29.755111

## About this project

This study investigates the microstructural organization of human cortical organoids using diffusion MRI, with a particular focus on spatial reproducibility, diffusion-time dependence, and biophysical modeling.

The repository is intended to include the code used for diffusion MRI analysis, analytical exchange simulations, Monte Carlo simulations, and trajectory-based validation.
